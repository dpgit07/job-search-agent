Draft a networking/outreach message. Usage: /outreach {type} {company_or_person}

Types: recruiter | referral | followup | thankyou | linkedin

Steps:
1. Look up the target company/role from tracker if applicable
2. Invoke networking-assistant subagent
3. Present the draft message for review and editing

Examples:
- /outreach recruiter Google — cold outreach to a Google recruiter for a DE role
- /outreach referral Databricks — ask a connection for a referral at Databricks
- /outreach followup Meta — 1-week follow-up on Meta application
- /outreach thankyou Amazon — thank you note after Amazon interview
- /outreach linkedin Snowflake — LinkedIn connection request note
